Algorithmic Synergies Implemented in TrafficTwin

Global Exploration via GA: In every epoch, we perform tournament selection and arithmetic crossover between the top 40% candidate parameter vectors, followed by bounded Gaussian perturbation. This systematically prevents particles from collapsing into false local minima created by non-linear queue shockwaves.

Local Exploitation via PSO: Surviving particles update their velocities directed toward both their cognitive trajectory memory ($p_i^{\text{best}}$) and the global elite calibration vector ($g^{\text{best}}$). Inertia damping ($0.9 \to 0.4$) accelerates convergence precision once the global basin of attraction is discovered.
